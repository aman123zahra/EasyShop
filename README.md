# 🛍️ EasyShop

A static/dummy e-commerce shopping website created as a frontend web development project.

> **Note:** This is a static/demo project. Some features and navigation links are for demonstration purposes and are not fully functional.

## 📌 Features

- 🛍️ Product shopping interface
- 🔍 Product search
- 🛒 Add to Cart functionality
- ❤️ Wishlist functionality
- 📦 Product cards and categories
- 🎨 User-friendly shopping interface

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js

## 🎯 Project Purpose

EasyShop was created as a practical learning project to practice web development, frontend design, JavaScript functionality, and basic backend development.
